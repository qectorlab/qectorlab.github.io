ANTHROPIC CLAUDE CODE & DESKTOP PLUGIN · v2.0.1 · published 2026-11-06

QECTOR Claude Plugin

Empower Claude with local Quantum Error Correction engineering. Release v2.0.1 runs on qector-decoder-v3 1.0.1. The default qector-secure server is air-gapped, integrity-checked and validates every request and response against JSON Schema (12 tools). It ships with 28 domain skills, 5 specialized agents and 11 slash commands; 29 research tools and 3 admin tools are opt-in. Every dependency is pinned by SHA-256, and releases are signed.

claude plugin marketplace add GuillaumeLessard/qector-claude-plugin

Local-First Security

Local stdio transport by default. Parity matrices, syndromes, quantum circuits, and simulation artifacts are processed on the host machine; verify your host environment if confidentiality matters.

Strict Mathematics

Decodes are checked against H c = s (mod 2). Scored with logical cosets and Wilson 95% CIs.

App-Free Library

Built on the official qector-decoder-v3 1.0.x Rust/PyO3 wheel. No desktop GUI required.

Multi-Agent System

28 domain skills and 5 tailored agent personas designed for research, hardware design, verification, and engineering.

Installation & Setup

Configure QECTOR Claude Plugin v2.0.1 for Claude Code or Claude Desktop in seconds.

1

Claude Code Marketplace

Install directly via Claude Code marketplace registration:

# 1. Add marketplace repository
claude plugin marketplace add GuillaumeLessard/qector-claude-plugin

# 2. Install plugin
claude plugin install qector@qector-tools
2

Local Plugin Directory

Clone the source repository and launch with the --plugin-dir flag:

git clone https://github.com/GuillaumeLessard/qector-claude-plugin.git
cd qector-claude-plugin
pip install --require-hashes -r requirements.lock
claude --plugin-dir .

Mathematical Validation Gate

Verify all 16 Reference Manual theorems and 29 executable proof obligations locally on your machine:

# Run the complete public reference manual mathematical gate
python scripts/run_manual_math_validation.py

# Or run full pytest integration suite
python -m pytest tests/test_reference_manual_math.py -v

Download Distribution Packages

Signed release archives: the Claude Code plugin, Claude Desktop extensions (.mcpb, including an offline bundle with a pinned wheelhouse), SHA256SUMS with its signature, an SBOM and provenance.
