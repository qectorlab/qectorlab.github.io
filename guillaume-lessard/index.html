Background

My engineering philosophy is rooted in practical execution. Over the course of my career, I learned to build robust systems because I wanted to make things that worked in the real world. That has been the method ever since: pick the problem, learn what the problem requires, ship the result, publish the evidence.

For most of the last twenty years that meant building high-performance applications and tools. I founded iD01t Productions in 2012. QECTOR serves as its dedicated QEC software division, delivering robust decoder pipelines for research and production environments.

Quantum error correction is where that method currently points. QECTOR Decoder v3 is a Rust core behind a Python API implementing 17+ decoder configurations, with v1.0.0 (August 2026) as the first stable release and v1.0.1 as the current one (2026-08-06). The public contract separates mathematical correctness from machine-specific performance: decodes can be checked against the declared syndrome relation, while local benchmark results carry their workload, environment, raw artifact, and hash. The qector Claude Plugin v2.0.1 extends the same evidence-first approach into local Claude Code and Claude Desktop workflows.
