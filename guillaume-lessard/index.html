Founder and Lead Engineer, QECTOR

Guillaume Lessard

I build quantum error correction decoders in Rust and Python, and the release and licensing infrastructure that lets teams trust them: corrections checked against their syndromes, wheels with verifiable provenance, and licences that work air-gapped. Based in Longueuil, Québec.

What I work on

Decoders that prove their output

A Rust core behind a Python API: Union-Find, exact MWPM, BP-OSD and Relay-BP for qLDPC codes, on CPU and GPU. Every correction is checked against its syndrome, H·c = s (mod 2).

Releases you can verify

Wheels built in public CI, tested on each operating system before publishing, with Sigstore provenance, PyPI attestations and Trusted Publishing.

Tools that stay offline

Air-gapped licensing with Ed25519 tokens, a schema-validated MCP server for Claude, and a self-contained desktop Workbench.
