Installation

QECTOR Decoder v3 ships as a Rust-compiled Python wheel for Python 3.9–3.13 on Linux x86_64, macOS (ARM64/x86_64), and Windows x64.

pip install qector-decoder-v3==0.6.9

# Optional extras
pip install "qector-decoder-v3[stim]"   # Stim / Sinter / PyMatching / LDPC
pip install "qector-decoder-v3[bench]"  # Benchmark harness
pip install "qector-decoder-v3[all]"    # Full environment

# Verify
python -c "import qector_decoder_v3 as qd; print(qd.__version__)"
  • Linux: manylinux2014 wheels (Ubuntu 20.04+, Debian 11+, RHEL 8+).
  • macOS: universal2 wheels, macOS 12+.
  • Windows: 10/11 x64 wheels; GPU batch requires NVIDIA CUDA 11.8+.
