Technical Reference

API overview for QECTOR's decoders. The guided examples below are illustrative; the API index at the end of this page is generated from the published 1.0.1 package.

Decoder Classes

BlossomDecoder

Minimum-weight perfect matching (MWPM) decoder for CSS stabilizer codes. Uses an exact matching solver to pair syndrome checks.

Signature
BlossomDecoder(dem: stim.DetectorErrorModel, *, adaptive_k: bool = True, timeout: Optional[float] = None)
Parameters
NameTypeDefaultDescription
demstim.DetectorErrorModelRequiredDetector error model of the circuit
adaptive_kboolTrueEnable Union-Find pre-filtering to compress graph
timeoutfloatNoneMax seconds allowed to match a syndrome
Usage Example
blossomdecoder_usage.pypython
import qector_decoder_v3 as qd
decoder = qd.BlossomDecoder(dem)
correction = decoder.decode(syndrome)
