QECTOR WorkbenchQECTOR Workbench

The free desktop application and Model Context Protocol server for QECTOR Decoder v3. Each v1.0.7 release (Windows/Linux) names 19 kinds: 17 concrete decoder configurations plus the AutoDecoder and Auto Router orchestration entries. It also covers 10 quantum code families, a visual circuit builder, and an 85-tool MCP server, with a bundled qector_decoder_v3 1.0.0 backend. Available for Windows x64 and Linux x64. Ships as a portable executable: each one is self-contained, bundling its own Python runtime, scientific stack, and decoder wheel. No system Python, no pip, and no online update checks.

Workbench Components

Desktop GUI

CustomTkinter desktop UI for Windows and Linux. Visual circuit builder, syndrome viewer, decoder performance dashboard, and a distance slider covering d3-d63 on supported families.

MCP Tools

Native Model Context Protocol server over stdio JSON-RPC 2.0, launched with --mcp and usable headlessly with no display. Connects AI agents directly to decoder execution and diagnostics.

Self-Contained

Bundles its own Python runtime, the scientific stack, and the qector_decoder_v3 1.0.0 wheel. No system Python or pip required; the app makes no online update checks.

Self / Auto-Debug Layer

Verifies H·c == s on every decode with a full attempt trace, and falls back across decoders automatically when a decoder fails to produce a faithful correction.

Hardware Dashboard

Auto-detects CUDA, OpenCL, and CPU backends, and reports OpenCL absence honestly: it names why a backend is unavailable rather than printing a bare N/A.

Lab & Personal Info

Deposit profile (author, ORCID, affiliation, DOI, funding, keywords) for generated reports, plus decoder license-key installation with a live tier readout.

Documentation Export

Export documentation and evidence in the formats supported by the selected release, with optional .zenodo.json and CITATION.cff deposit sidecars.

Bundled Manuals & EULA

Each release ships an API Reference, MCP Integration Guide, Quick Start Guide, a per-OS User Manual, a machine-readable LLM manual, and EULA.txt, with SHA-256 checksums for every file.
